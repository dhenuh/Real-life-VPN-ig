# Doppler-Effect location countermeasure

Basically a method was publicized recently using an api about airplane paths and mapping the sound's to locate any video with extreme precision. This project seeks to counteract this by producing valid doppler curves. A next level implementation is to make it a real life VPN where you can select which location you want to be perceived from. The program would then predict the doppler curve and attempt to replicate. 


Doppler effect for sound emitted by a moving airborne source and received by acoustic sensors located above and below the sea surface:
https://pubmed.ncbi.nlm.nih.gov/8300959/
